## Kök ve görev

Önce boşluğun kelime türünü belirle. `a ___ explanation` sıfat; `explain ___` zarf; `the ___ of…` çoğunlukla isim. Sonra anlamı seç. Her kök bütün ekleri doğal olarak almaz; hayali sözcük üretme.

| Ek | İşlev | Örnek aile |
|---|---|---|
| un-, in-/im-/il-/ir-, dis-, non- | Olumsuzluk/karşıtlık | reliable→unreliable; possible→impossible; legal→illegal |
| re-, pre-, post- | Tekrar/önce/sonra | reassess; pre-existing; post-war |
| over-, under-, mis- | Aşırılık/yetersizlik/yanlışlık | overestimate; underestimate; misinterpret |
| -tion/-sion, -ment, -ance/-ence | İsimleşme | assess→assessment; intervene→intervention; differ→difference |
| -ity, -ness | Özellik ismi | stable→stability; aware→awareness |
| -er/-or, -ist | Kişi/araç/uzman | research→researcher; biology→biologist |
| -ise/-ize, -ify, -en | Fiil | modernise/modernize; classify; strengthen |
| -al, -ive, -ous, -able/-ible, -ic | Sıfat | region→regional; effect→effective; access→accessible |
| -ly | Çoğunlukla zarf | significant→significantly; careful→carefully |

`friendly` sıfat; `fast` hem sıfat hem zarf; `hardly` hard'ın sıradan zarfı değildir. İngiliz/ABD `-ise/-ize` varyantı çoğu örnekte anlam farkı yaratmaz.

## Sık Tuzak

| Çift | Ayrım | Örnek |
|---|---|---|
| economic / economical | Ekonomiyle ilgili / tasarruflu | economic policy / an economical engine |
| historic / historical | Tarih açısından önemli / tarihle ilgili | a historic agreement / historical records |
| effective / efficient | Sonuç veren / kaynakları iyi kullanan | an effective remedy / an efficient process |
| considerable / considerate | Önemli miktarda / düşünceli | considerable damage / a considerate colleague |
| dependent / dependable | Bağımlı / güvenilir | dependent on aid / a dependable device |
| affect / effect | Çoğunlukla fiil “etkilemek” / isim “etki” | affect growth / an effect on growth |
| rise / raise | Geçişsiz artmak / geçişli artırmak | prices rise / firms raise prices |
| sensitive / sensible | Hassas / akla uygun | sensitive data / a sensible decision |

`effect` “meydana getirmek” fiili de olabilir: `effect a change`; görev ve bağlamı kontrol et. `historic/historical` bazen örtüşse de sınavda öne çıkarılan anlamı seç.

## False friends

- **actually:** aslında; “aktüel” değil. `current` güncel/mevcut.
- **eventually:** sonunda; “muhtemelen” değil (`possibly`).
- **actual:** gerçek; “güncel” değil.
- **sympathetic:** anlayışlı/duygudaş; fiziksel “sempatik” her bağlamda karşılanmaz.
- **fabric:** kumaş; fabrika `factory`.
- **comprehensive:** kapsamlı; anlaşılır `comprehensible`.
- **novel:** isim roman, sıfat yeni/özgün; metinde görevini seç.
- **policy / politics / politician:** ilke/politika çizgisi / siyaset / siyasetçi.

## Kısa çalışma

`The intervention was effective.` → `The effectiveness of the intervention…`. İsimleşince “etkili olma” özelliği isim olur. `The workers operated efficiently.` → `an efficient operation`. [Gramer atölyesi](../practice/review/grammar-workshop.md) ve [kelime drill](../question-types/01-vocabulary-phrasal-verbs/practice.md) ile kapalı notla dene.
