# Modals — Güç, Olasılık ve Geçmiş

[Başlangıç](../README.md) · [Temeller](../fundamentals/README.md) · [Aktif hatırlama](active-recall-bank.md)

## Biçim

Core modal + V1: `may change`, `must be`; `-s` ve `to` almaz. `ought to / have to / used to` farklı yapılardır. `has to change`, `does not have to change` çekilir. Modal sonrası passive `be + V3`, perfect `have + V3` olabilir.

| Yapı | Temel anlam | Örnek | Sık tuzak |
|---|---|---|---|
| can | Yetenek, izin, genel olasılık | Small errors can affect the outcome. | Tek olaya ilişkin “belki” için may/might sık daha uygun |
| could | Geçmiş genel yetenek, ihtimal, nazik rica | Earlier instruments could detect only large changes. | Tek başarılı geçmiş eylemde was able to çoğu zaman daha açık |
| may / might | Olasılık; may ayrıca izin | The decline might reflect a temporary shortage. | Kesin neden ilan etmez; yüzdelik kesinlik atama |
| must | Zorunluluk veya güçlü çıkarım | The lights are on; someone must be inside. | `must not` yasak; “gerek yok” değil |
| have to | Koşullardan/kuraldan zorunluluk | Applicants have to provide identification. | must/have to ayrımı her bağlamda katı değil |
| should / ought to | Tavsiye, beklenti | The treatment should reduce discomfort. | should her zaman ahlaki görev değildir |
| need to | Gereklilik | We need to check the source. | Çekilir: needs to / didn't need to |
| needn't | Gereklilik yok | You needn't repeat the experiment. | `needn't to` olmaz |
| would | Varsayım, geçmiş alışkanlık, nazik istek | Without funding, the project would fail. | Geçmiş durum alışkanlığında used to; `would own` uygun olmayabilir |
| used to | Geçmişte alışkanlık/durum, artık farklı | The region used to depend on coal. | `be used to + noun/V-ing` “alışkın olmak” |

## Modal + have + V3

| Yapı | Geçmiş değerlendirmesi | Örnek ve yorum |
|---|---|---|
| must have V3 | Güçlü geçmiş çıkarımı | The chamber is empty; the team must have removed the objects. — Çıkarmış olmalılar. |
| may/might have V3 | Geçmiş olasılık | The signal may have been interrupted. — Kesilmiş olabilir. |
| can't/couldn't have V3 | Geçmiş imkânsızlık çıkarımı | The device was unplugged; it can't have recorded the event. |
| could have V3 | Kullanılmamış imkân veya geçmiş olasılık | We could have saved the data, but we closed the program. |
| should/ought to have V3 | Eleştiri/pişmanlık; bağlama göre geçmiş beklenti | They should have warned us. / The parcel should have arrived by now. |
| needn't have V3 | Yapıldı ama gereksizdi | You needn't have printed it; we already had copies. |
| would have V3 | Gerçekleşmemiş koşulun sonucu | With more time, we would have checked every entry. |

**didn't need to** yalnızca gerek olmadığını söyler; işin yapılıp yapılmadığını tek başına belirlemez. **needn't have** işin yapıldığını bildirir. `must have` kanıta dayalı çıkarımdır; geçmiş zorunluluk genellikle `had to` ile kurulur. “Yapmış olmalı” ile “yapmak zorundaydı” farklıdır.

## Modal gücü çeviride koru

`may help` → yardımcı olabilir; `will help` → yardımcı olacaktır; `must help` → yardım etmeli (zorunluluk bağlamı). Bağlam olmadan aynı Türkçe ek her modalı karşılamaz. Restatement'ta “might”ı “certainly” ile değiştiren seçenek güç artırır.
