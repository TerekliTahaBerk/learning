# Restatement / Closest Meaning

[On tür](../README.md) · [Başlangıç](../../README.md) · [Uygulama](practice.md) · [Yanıtlar](answers.md)

## Anlamın sekiz değişmezi

**actor, action, time, polarity, degree, cause, condition, certainty**. Yüzeyde aynı kelimeler olup bu ögelerden biri değişiyorsa yakın anlam korunmaz. Çok farklı kelimeler aynı ilişkiyi kurabilir.

## Dönüşüm haritası

| Dönüşüm | Güvenli örnek | Sınır |
|---|---|---|
| because ↔ since/as | Because demand fell… / Since demand fell… | since zaman da bildirir |
| although ↔ despite | Although costs rose… / Despite the rise in costs… | clause → noun/V-ing dönüşümü gerekli |
| because of ↔ due to | because of the delay / due to the delay | nedeni koru |
| if not ↔ unless | If funding is not secured… / Unless funding is secured… | kapsam ve karşı-olgusal bağlamı kontrol et |
| active ↔ passive | The team checked it. / It was checked by the team. | yapan, tense, modal korunmalı |
| clause ↔ nominalization | Demand declined rapidly. / There was a rapid decline in demand. | actor/neden kaybolabilir |
| cause ↔ result | Because it rained, work stopped. / It rained; therefore, work stopped. | neden-sonuç yönünü koru |
| reduction | Data that were collected… / Data collected… | bağlam ve zaman kaybı olmamalı |

## Kritik koşul yönleri

`We will proceed only if permission is granted.` İzin gerekli: ilerlersek izin verilmiş olacaktır. İzin verilmesi tek başına ilerleyeceğimizi garanti etmez. `If permission is granted, we will proceed` yeterli şart bildirir; aynı anlam değildir. `provided that` açık şart getirir; her bağlamda only if ile mekanik değişmez.

`Not until Friday did they publish.` Cuma'dan önce yayımlamadılar; Cuma yayımladılar. `They published before Friday` ters. `rather than` bir alternatifi dışlar; `as well as` ekler. `They measured cost rather than speed` iki ölçüm yaptılar demek değildir.

## Modal eşdeğerliği

`may = it is possible that` uygun olasılık bağlamında; `must = it is necessary to` yalnız zorunluluk anlamında. `must be inside` çıkarım; “içeride olması gerekiyor” aynı değil. `should have` eleştiri veya beklenti olabilir.

## Çözümlü örnek

`Although the intervention reduced symptoms, it did not remove the underlying cause.`

`Despite reducing symptoms, the intervention failed to eliminate the underlying cause.` Aktör ve iki etki korunur. “It removed the cause but not the symptoms” etkiyi ters çevirir; “It could reduce symptoms” gerçekleşmişliği olasılığa çevirir.

Cevap seçmeden değişmezleri kısa notla yaz; iki yakın seçeneğin farkını tek kelimeyle belirle: **all / some**, **may / must**, **before / after**.
