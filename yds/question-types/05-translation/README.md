## Anlam haritası

Kelime kelime çeviri yerine yapı haritası çıkar: ana özne → ana yüklem → nesne → yan cümleler → niteleyici → bağlaç → tense/modal → olumsuzluk. Türkçede yüklemin sonda oluşu, İngilizce nesne ve modifier ilişkisini değiştirmez.

## English → Turkish

`Although the samples that were collected locally were small, they may provide useful evidence.`

Ana özne **samples**, relative **that were collected locally**, taviz **although**, ana sonuç **may provide**, nicelik **small**. Doğal çeviri: “Yerel olarak toplanan örnekler küçük olsa da yararlı kanıt sağlayabilir.” `may`ı “sağlayacaktır” yapma; collected'ın öznesi samples, researchers değil.

## Turkish → English

“Yalnızca maliyetleri azaltan yöntemler uygulamaya alınacak.”

`Only methods that reduce costs will be implemented.` `Only` methods grubunu sınırlar; bütün yöntemlerin maliyet azaltacağı veya yöntemin yalnız maliyeti azalttığı anlamı yoktur. `Methods will only reduce costs` eylemin kapsamını değiştirir.

## Seçenek kontrol matrisi

| Kontrol | Sık hata |
|---|---|
| Aktör ve etkilenen | Öğrenci öğretmeni değerlendiriyor ↔ öğretmen öğrenciyi |
| Zaman | Daha önceki olay ↔ güncel eylem |
| Modal | may ↔ must / kesin sonuç |
| Olumsuzluk | not all ↔ none |
| Connector | despite ↔ because of |
| Niteleyici | Hangi isim niteleniyor? |
| Derece | some ↔ all; more ↔ most |
| Kapsam | only hangi ögeyi sınırlıyor? |

## Sık Tuzak

`associated with` ilişkili, doğrudan “neden olur” değil. `could have` olasılık veya gerçekleşmemiş imkân; çevre cümleyi oku. `the rapid decline in demand` hızlı azalan demand, decline'a karşılık rapid sıfat.

## Çalışma
