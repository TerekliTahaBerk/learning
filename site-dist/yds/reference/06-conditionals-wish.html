Conditionals, Wish ve If Only

Başlangıç · Temeller · Aktif hatırlama

Koşul tipi, olayın zamanını ve konuşanın gerçeklik tutumunu birleştirir. Aşağıdaki kalıplar merkez örneklerdir; modal değişebilir. İkinci koşuldaki past biçim her zaman geçmiş zamanı anlatmaz.

Tür Yaygın kalıp Anlam Örnek
Zero if + present, present Genel ilişki If demand rises while supply stays fixed, prices often increase.
First if + present, will/can/may + V1 Gerçekleşebilir gelecek If the review ends today, we will publish tomorrow.
Second if + past, would/could/might + V1 Şimdi/gelecek varsayım If we had more staff, we could test more samples.
Third if + had V3, would/could/might have V3 Geçmiş karşı-olgusal If they had checked the valve, they might have prevented the leak.
Mixed: geçmiş → şimdi if + had V3, would + V1 Geçmiş nedenin şimdiki sonucu If she had accepted the post, she would live abroad now.
Mixed: durum → geçmiş if + past, would have V3 Genel/şimdiki durumun geçmişe etkisi If I were more careful, I would not have deleted the file.

Resmî varsayımsal kullanımda If I were… yaygın; was da özellikle konuşmada görülür. Normal gelecek koşulda if-clause'a will koyma; ancak isteklilik/rica anlamında if you will… mümkündür. Tek bir kelimeyi mutlak yasak diye ezberleme.

Alternatif koşullar

İfade İşlev Örnek
unless if…not: belirtilen istisna yoksa Unless the sample is labelled, we cannot use it.
provided/providing that açık şart We can proceed provided that permission is granted.
as long as şart; ayrıca süre anlamı olabilir You may stay as long as you follow the rules.
on condition that resmî şart The archive granted access on condition that no images were published.
otherwise aksi durumda, önceki şartın sağlanmaması Back up the files; otherwise, you may lose them.

unless sonrası ikinci bir not, amaçlanmayan çift olumsuzluk yaratabilir. Her if not mekanik olarak unless olmaz: karşı-olgusal pişmanlık veya farklı kapsamda anlamı yeniden kontrol et. only if gerekli şarttır; if ile yönü aynı değildir. Restatement.

Wish / if only

Hedef Yapı Örnek ve anlam
Şimdiki durumdan hoşnutsuzluk wish + past I wish I knew the answer. — Keşke bilsem.
Geçmiş pişmanlık wish + had V3 I wish I had saved the file. — Keşke kaydetseydim.
İstenen değişim / şikâyet wish + would V1 I wish the neighbours would stop shouting.
Yetenek/imkân isteği wish + could V1 I wish I could read the inscription.

If only aynı temel zaman ilişkilerini daha güçlü duyguyla kurabilir. Geleceğe yönelik gerçekçi umut hope: I hope the review finishes soon. Kendi isteyerek denetlediğin eylem için I wish I would study genellikle doğal değil; I wish I studied more veya niyet ifadesi kullan.

Ters koşul

Had they checked… = If they had checked…; Were funding available… = If funding were available…; Should problems arise… = If problems should arise…. If düşer, yardımcı öznenin önüne gelir.
