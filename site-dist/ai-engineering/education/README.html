AI Engineering Education

This section organizes structured learning materials for AI Engineering courses and other educational resources.

Learning workflow

  1. Create a course-specific folder for each learning track or source.
  2. Store original PDFs and other source materials in that folder's pdfs/ directory.
  3. Study each topic with clear explanations and examples.
  4. Add concise, well-organized English notes to that course folder's notes/ directory.
  5. Put reusable practice in ../exercises/ and larger applied work in ../projects/.

See DataCamp Associate AI Engineer for Developers for the first course setup.
