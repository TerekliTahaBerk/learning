# Sık Düzensiz Fiiller

| Mastar | Şimdiki zaman önemli biçimler | Türkçe | Örnek |
|---|---|---|---|
| ser | soy, eres, es, somos, sois, son | olmak (kimlik/sınıf vb.) | Somos de Ankara. |
| estar | estoy, estás, está, estamos, estáis, están | olmak/bulunmak | El café está abierto. |
| ir | voy, vas, va, vamos, vais, van | gitmek | Voy al trabajo. |
| tener | tengo, tienes, tiene, tenemos, tenéis, tienen | sahip olmak/yaş | Tengo una hermana. |
| hacer | hago, haces, hace, hacemos, hacéis, hacen | yapmak/hava | Hace frío. |
| venir | vengo, vienes, viene, venimos, venís, vienen | gelmek | ¿Vienes mañana? |
| poder | puedo, puedes, puede, podemos, podéis, pueden | -ebilmek | ¿Puedes ayudarme? |
| querer | quiero, quieres, quiere, queremos, queréis, quieren | istemek/sevmek | Quiero aprender. |
| decir | digo, dices, dice, decimos, decís, dicen | söylemek | Dice que sí. |
| haber | he, has, ha, hemos, habéis, han; hay | yardımcı fiil; var | Hay dos sillas. |

Bunları tek tabloda ezberlemek yerine modül bağlamında üret. Özellikle `ser/estar`, `ir/venir`, `pedir/preguntar` anlam ayrımlarını [Türkçe konuşanlar rehberi](12-turkish-speaker-guide.md) üzerinden çalış.

## Biçim aileleri

| Aile | Fiiller ve ayırt edici biçim | Türkçe çalışma ipucu |
|---|---|---|
| Çok yüksek sıklık | `ser: soy/fui/sea`; `ir: voy/fui/vaya`; `haber: hay/he/haya` | `ser` ile `ir`in indefinido biçimi aynıdır; bağlam karar verir. |
| `yo` biçiminde `-go` | `tener: tengo`; `venir: vengo`; `poner: pongo`; `salir: salgo`; `hacer: hago`; `decir: digo`; `oír: oigo` | Diğer kişiler de düzensiz olabilir: `tienes`, `vienes`, `dices`. |
| `e→ie` | `pensar: pienso`; `querer: quiero`; `empezar: empiezo`; `entender: entiendo`; `cerrar: cierro` | Kök değişimi şimdiki zamanda `nosotros/vosotros`da genellikle yoktur. |
| `o→ue` | `poder: puedo`; `volver: vuelvo`; `dormir: duermo`; `encontrar: encuentro`; `contar: cuento` | Mastarı ve birinci tekili birlikte kaydet. |
| `e→i` | `pedir: pido`; `seguir: sigo`; `repetir: repito`; `servir: sirvo` | `pedir` = istemek; `preguntar` = soru sormak. |
| Yazımı koruma | `buscar: busqué`; `llegar: llegué`; `empezar: empecé` | Ses korunurken harf değişebilir. |
| Indefinido düzensiz kök | `tener: tuv-`; `estar: estuv-`; `poder: pud-`; `poner: pus-`; `saber: sup-`; `venir: vin-`; `hacer: hic-`; `decir: dij-`; `traer: traj-` | `tuve, tuviste, tuvo, tuvimos, tuvisteis, tuvieron` modelini izle. |
| Düzensiz ortaç | `hecho, dicho, visto, escrito, puesto, abierto, vuelto, roto, muerto, cubierto` | `haber` ile değişmez: `he visto`; sıfat olursa uyumlanır: `la ventana abierta`. |
| Gelecek/koşul kökü | `tendr-, vendr-, podr-, pondr-, saldr-, dir-, har-, querr-, sabr-` | Aynı köke gelecek `-é`, koşul `-ía` eklenir: `tendré/tendría`. |
| Subjuntivo | `ser: sea`; `ir: vaya`; `estar: esté`; `haber: haya`; `saber: sepa`; `dar: dé` | İstisnaları kısa işlevsel cümleyle öğren. |
| Olumlu `tú` emri | `di, haz, ve, pon, sal, sé, ten, ven` | Olumsuz emirde subjuntivo: `no digas`, `no hagas`, `no vayas`. |
