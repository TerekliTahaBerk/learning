# Yaygın Eşdizimler

| İfade | Anlam | Örnek |
|---|---|---|
| tener hambre / sed / sueño | acıkmış / susamış / uykulu olmak | Tengo sueño. |
| tener razón | haklı olmak | Tienes razón. |
| hacer una pregunta / una foto | soru sormak / fotoğraf çekmek | ¿Puedo hacer una pregunta? |
| dar un paseo | yürüyüş yapmak | Damos un paseo después de cenar. |
| quedar con alguien | biriyle buluşmak | He quedado con Marta. |
| pedir ayuda / la cuenta | yardım / hesap istemek | Pedimos la cuenta, por favor. |
| darse cuenta de | fark etmek | Me di cuenta del error. |
| tomar una decisión | karar vermek | Tenemos que tomar una decisión. |
| llevar a cabo | gerçekleştirmek | El equipo llevó a cabo el estudio. |
| tener en cuenta | göz önünde bulundurmak | Hay que tener en cuenta el coste. |
| poner en marcha | başlatmak | Pusieron en marcha el proyecto. |
| llegar a un acuerdo | anlaşmaya varmak | Llegaron a un acuerdo. |

Eşdizimi sözcük sözcük Türkçeden çevirmeye çalışma; tam kalıp ve örnekle öğren.

## Tematik tekrar bankası

| Düzey | Alan | Eşdizim — Türkçesi | Örnek |
|---|---|---|---|
| A1 | ihtiyaç | `tener hambre/sed/sueño` — aç/susamış/uykulu olmak | `Tenemos hambre; vamos a comer.` |
| A1 | günlük yaşam | `hacer la compra` — alışveriş yapmak | `Hago la compra los sábados.` |
| A1 | hareket | `tomar el autobús` — otobüse binmek | `Tomo el autobús a las ocho.` |
| A1 | iletişim | `hacer una pregunta` — soru sormak | `Quiero hacer una pregunta.` |
| A2 | sosyal yaşam | `quedar con alguien` — biriyle buluşmak | `Quedé con Laura ayer.` |
| A2 | hizmet | `pedir una cita` — randevu almak | `Pedí una cita para el martes.` |
| A2 | karar | `cambiar de opinión` — fikir değiştirmek | `Cambió de opinión al leer el menú.` |
| A2 | olay | `perder el tren` — treni kaçırmak | `Perdimos el tren por cinco minutos.` |
| B1 | gerekçe | `plantear un problema` — sorun ortaya koymak | `El informe plantea un problema.` |
| B1 | hedef | `cumplir un objetivo` — hedefe ulaşmak | `Cumplimos el objetivo este mes.` |
| B1 | iş | `tomar una decisión` — karar vermek | `Tomamos una decisión en la reunión.` |
| B1 | dikkat | `prestar atención a` — dikkat etmek | `Presta atención a la fuente.` |
| B2 | tartışma | `tener en cuenta` — göz önünde bulundurmak | `Hay que tener en cuenta el contexto.` |
| B2 | proje | `llevar a cabo` — yürütmek | `Llevaron a cabo un estudio piloto.` |
| B2 | analiz | `llegar a una conclusión` — sonuca varmak | `No podemos llegar a una conclusión todavía.` |
| B2 | kanıt | `poner de manifiesto` — ortaya koymak | `Los datos ponen de manifiesto la desigualdad.` |
| B2 | rol | `desempeñar un papel` — rol oynamak | `La escuela desempeña un papel clave.` |
| B2 | değerlendirme | `sacar una conclusión` — sonuç çıkarmak | `No saques conclusiones de una sola cifra.` |

Fiilin gerektirdiği edatı ifadeyle birlikte öğren; `prestar atención a` kalıbındaki `a` tesadüfi değildir. Her düzey sonunda iki eski kalıbı yeni konuya taşı.
