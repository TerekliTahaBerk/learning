# Türkçe Konuşanlar İçin Hata Bankası

Hatalar bir değerlendirme aracıdır: yanlış biçimi gerekçesiyle düzelt, sonra aynı yapıyı kendi bağlamında yeni cümleyle üret. `*`/❌ yalnızca öğretim amaçlı hatalı örneği işaretler.

## A1

| ❌ | ✅ | Neden ve ders |
|---|---|---|
| `Mi llamo Ece.` | `Me llamo Ece.` | `me` dönüşlü zamirdir; `mi` iyelik. [M01](../levels/a1/01-selamlasma-ve-tanisma/02-gramer.md) |
| `Soy 22 años.` | `Tengo 22 años.` | Yaş `tener` ile. [M02](../levels/a1/02-kimlik-ulkeler-ve-meslekler/02-gramer.md) |
| `Mis hermana es alto.` | `Mi hermana es alta.` | İyelik sayısı ve sıfat cinsiyeti. [M03](../levels/a1/03-aile-ve-insanlari-tanimlama/02-gramer.md) |
| `Levanto a las siete.` | `Me levanto a las siete.` | Kişinin kalkması dönüşlü. [M04](../levels/a1/04-gunler-tarih-saat-ve-rutin/02-gramer.md) |
| `Hay el banco aquí.` | `El banco está aquí.` | Belirli yerin konumu. [M05](../levels/a1/05-ev-ve-sehir/02-gramer.md) |
| `Me gusta las verduras.` | `Me gustan las verduras.` | Beğenilen şey çoğul özne. [M06](../levels/a1/06-yemek-ve-restoran/02-gramer.md) |
| `Voy visitar el museo.` | `Voy a visitar el museo.` | `ir a + mastar`. [M08](../levels/a1/08-bos-zaman-hava-ve-planlar/02-gramer.md) |

## A2

| ❌ | ✅ | Neden ve ders |
|---|---|---|
| `He visitada Granada.` | `He visitado Granada.` | `haber` ile ortaç değişmez. [M01](../levels/a2/01-gecmis-deneyimler-ve-hayat-olaylari/02-gramer.md) |
| `Él hació la reserva.` | `Él hizo la reserva.` | Düzensiz indefinido. [M02](../levels/a2/02-gecmiste-olaylar-ve-anilar/02-gramer.md) |
| `Cuando era niño, jugué cada tarde.` | `Cuando era niño, jugaba cada tarde.` | Geçmiş alışkanlık imperfecto. [M03](../levels/a2/03-gecmiste-aliskanlik-ve-arka-plan/02-gramer.md) |
| `Quiero lo reservar.` | `Quiero reservarlo.` | Zamir mastara bitişir veya çekimli fiilden önce gelir. [M04](../levels/a2/04-seyahat-konaklama-ve-sorun-cozme/02-gramer.md) |
| `Le lo envié.` | `Se lo envié.` | `le/les` doğrudan nesne zamiri önünde `se` olur. [M04](../levels/a2/04-seyahat-konaklama-ve-sorun-cozme/02-gramer.md) |
| `No toma este medicamento.` | `No tomes este medicamento.` | Samimi olumsuz emir. [M05](../levels/a2/05-saglik-aliskanliklar-ve-tavsiyeler/02-gramer.md) |
| `Es más mejor.` | `Es mejor.` | Temel üstün karşılaştırma `mejor`. [M06](../levels/a2/06-karsilastirma-sehir-ve-hizmetler/02-gramer.md) |
