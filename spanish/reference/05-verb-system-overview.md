# Fiil Sistemi: Genel Bakış

İspanyolca fiil çekimi kişi ve zamanı çoğu kez fiil sonundan gösterir; bu yüzden özne zamiri bağlam açıksa düşebilir: `Trabajo` = (ben) çalışıyorum. Vurgulamak/karşılaştırmak için zamir eklenir: `Yo trabajo, pero ella estudia.`

## Düzenli şimdiki zaman

| Kişi | hablar | comer | vivir |
|---|---|---|---|
| yo | hablo | como | vivo |
| tú | hablas | comes | vives |
| él/ella/usted | habla | come | vive |
| nosotros/as | hablamos | comemos | vivimos |
| vosotros/as | habláis | coméis | vivís |
| ellos/ellas/ustedes | hablan | comen | viven |

Bölgesel seçim: İspanya'da çoğul samimi hitap çoğunlukla `vosotros`; Latin Amerika'da `ustedes`. Öğrenirken tabloda ikisini tanı.

## Düzensizlik türleri

1. Kök değişimi: `pensar → pienso`, `poder → puedo`, `pedir → pido` (çoğu zaman nosotros/vosotros biçimleri değişmez).
2. Birinci tekil kişi: `tener → tengo`, `hacer → hago`, `salir → salgo`.
3. Özel yüksek sıklık: `ser, estar, ir, haber` biçimlerini ayrı öğren.
4. Geçmiş zaman düzensiz kökü/ortaç: `tener → tuve`, `hacer → hice`, `hacer → hecho`.

İspanyolca mastar `-ar/-er/-ir` ile biter. Türkçedeki eklemeli yapıdan farklı olarak kişi/zaman bilgisi fiil çekiminde birikir; ayrıca kip seçimi konuşanın olguya tutumunu gösterebilir. Sıralama: A1 düzenli şimdiki → düzensizler → yakın gelecek; A2 geçmişler → emir; B1 subjuntivo/koşul → B2 zaman uyumu.
