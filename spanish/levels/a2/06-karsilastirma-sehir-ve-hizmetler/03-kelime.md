# Kelime ve kullanışlı parçalar · Karşılaştırma, şehir ve hizmetler

İsimlerde artikel ve çoğulu, fiillerde birlikte kullanılan edatı kaydet. `—` veya “genelde tekil” notu kullanımın türünü belirtir; sözlükteki bütün olası kullanımları dışlamaz.

| İspanyolca | Türkçe | Çoğul / tür | Bağlamlı örnek — Türkçesi |
|---|---|---|---|
| `el barrio` | mahalle | los barrios | Este barrio es tranquilo. — Bu mahalle sakin. |
| `el centro` | merkez | los centros | El centro está lejos. — Merkez uzak. |
| `el transporte público` | toplu taşıma | genelde tekil | El transporte público funciona bien. — Toplu taşıma iyi işliyor. |
| `el autobús` | otobüs | los autobuses | Hay muchos autobuses. — Çok otobüs var. |
| `el tranvía` | tramvay | los tranvías | El tranvía es rápido. — Tramvay hızlı. |
| `el metro` | metro | los metros | Voy en metro. — Metroyla gidiyorum. |
| `la parada` | durak | las paradas | La parada está cerca. — Durak yakın. |
| `el servicio` | hizmet | los servicios | Este servicio es útil. — Bu hizmet yararlı. |
| `el centro de salud` | sağlık merkezi | los centros de salud | Hay un centro de salud. — Sağlık merkezi var. |
| `la biblioteca` | kütüphane | las bibliotecas | Estudio en la biblioteca. — Kütüphanede çalışıyorum. |
| `el mercado` | pazar | los mercados | Compro fruta en el mercado. — Pazardan meyve alırım. |
| `el alquiler` | kira | los alquileres | El alquiler es caro. — Kira pahalı. |
| `el precio` | fiyat | los precios | Los precios subieron. — Fiyatlar arttı. |
| `el ruido` | gürültü | los ruidos | Hay mucho ruido. — Çok gürültü var. |
| `la tranquilidad` | sakinlik | genelde tekil | Busco tranquilidad. — Sakinlik arıyorum. |
| `la seguridad` | güvenlik | genelde tekil | La seguridad importa. — Güvenlik önemli. |
| `la ventaja` | avantaj | las ventajas | Tiene una ventaja. — Avantajı var. |
| `la desventaja` | dezavantaj | las desventajas | El precio es una desventaja. — Fiyat dezavantaj. |
| `comparar` | karşılaştırmak | fiil | Comparo dos barrios. — İki mahalleyi karşılaştırıyorum. |
| `elegir` | seçmek | fiil | Elijo el más tranquilo. — Daha sakin olanı seçiyorum. |
| `mejorar` | iyileşmek | fiil | El servicio mejoró. — Hizmet iyileşti. |
| `costar` | mal olmak | fiil | Cuesta más. — Daha pahalı. |
| `quedar cerca` | yakın olmak | kalıp | La parada queda cerca. — Durak yakın. |
| `ser mejor que` | ...den iyi olmak | kalıp | Es mejor que antes. — Eskisinden iyi. |
| `ser peor que` | ...den kötü olmak | kalıp | Es peor que antes. — Eskisinden kötü. |
| `más ... que` | ...den daha... | karşılaştırma | Es más barato que el centro. — Merkezden ucuz. |
| `menos ... que` | ...den daha az... | karşılaştırma | Hay menos ruido que antes. — Eskisinden az gürültü var. |
| `tan ... como` | ... kadar... | eşitlik | Es tan cómodo como el metro. — Metro kadar rahat. |
| `el más... de` | ...in en...i | üstünlük | Es el más tranquilo de todos. — Hepsinin en sakini. |
| `alguien` | biri | belirsiz | Alguien llamó. — Biri aradı. |
| `nadie` | kimse | olumsuz | No vino nadie. — Kimse gelmedi. |
| `algo` | bir şey | belirsiz | Necesito algo. — Bir şeye ihtiyacım var. |
| `nada` | hiçbir şey | olumsuz | No necesito nada. — Hiçbir şeye ihtiyacım yok. |
| `ningún` | hiçbir | sıfat | No hay ningún problema. — Hiç sorun yok. |
| `donde` | ...dığı yer | ilgi | La plaza donde quedamos. — Buluştuğumuz meydan. |

## Etkinleştirme

1. Türkçe sütununu kapatıp İspanyolca biçimi ve varsa artikeli/çoğulu üret.
2. Fiil ve kalıplarda en yakın doğal tamamlayıcıyı söyle.
3. Beş sözcüğü kendi hayatınla ilgili yeni cümlelere taşı.
4. Ertesi gün, üç gün sonra ve hafta sonunda kapalı notla yeniden üret.
