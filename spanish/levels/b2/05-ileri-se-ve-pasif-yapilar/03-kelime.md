# Kelime ve kullanışlı parçalar · İleri `se` kullanımları ve pasif yapılar

İsimlerde artikel ve çoğulu, fiillerde birlikte kullanılan edatı kaydet. `—` veya “genelde tekil” notu kullanımın türünü belirtir; sözlükteki bütün olası kullanımları dışlamaz.

| İspanyolca | Türkçe | Çoğul / tür | Bağlamlı örnek — Türkçesi |
|---|---|---|---|
| `la responsabilidad` | sorumluluk | las responsabilidades | La responsabilidad debe quedar clara. — Sorumluluk açık olmalı. |
| `el agente` | eylemi yapan | los agentes | El agente no aparece. — Fail belirtilmiyor. |
| `la acción` | eylem | las acciones | La acción se completó. — Eylem tamamlandı. |
| `el proceso` | süreç | los procesos | Se revisó el proceso. — Süreç incelendi. |
| `el resultado` | sonuç | los resultados | Se publicaron los resultados. — Sonuçlar yayımlandı. |
| `la publicación` | yayın | las publicaciones | La publicación fue ayer. — Yayın dün oldu. |
| `la entrevista` | görüşme | las entrevistas | Se entrevistó a diez personas. — On kişiyle görüşüldü. |
| `la persona responsable` | sorumlu kişi | las personas responsables | Se busca a la persona responsable. — Sorumlu kişi aranıyor. |
| `el protocolo` | protokol | los protocolos | Se actualizó el protocolo. — Protokol güncellendi. |
| `la norma` | kural | las normas | Se aprobaron nuevas normas. — Yeni kurallar onaylandı. |
| `la solicitud` | başvuru | las solicitudes | Se reciben solicitudes. — Başvurular alınıyor. |
| `el dato` | veri | los datos | Se trataron datos anónimos. — Anonim veriler işlendi. |
| `la privacidad` | gizlilik | genelde tekil | Se protege la privacidad. — Gizlilik korunuyor. |
| `el error` | hata | los errores | Se detectó un error. — Hata saptandı. |
| `el olvido` | unutma | los olvidos | Fue un olvido. — Bir unutmaydı. |
| `el accidente` | kaza | los accidentes | Se produjo un accidente. — Kaza oldu. |
| `la puerta` | kapı | las puertas | La puerta se abrió. — Kapı açıldı. |
| `el vaso` | bardak | los vasos | Se me rompió el vaso. — Bardak elimde kırıldı. |
| `la llave` | anahtar | las llaves | Se nos olvidaron las llaves. — Anahtarları unuttuk. |
| `el informe` | rapor | los informes | El informe fue publicado. — Rapor yayımlandı. |
| `publicar` | yayımlamak | fiil | Publicaron el informe. — Raporu yayımladılar. |
| `entrevistar a` | görüşmek | fiil | Entrevistaron a los vecinos. — Komşularla görüştüler. |
| `aprobar` | onaylamak | fiil | Se aprobó la medida. — Önlem onaylandı. |
| `detectar` | saptamak | fiil | Se detectó una falla. — Kusur saptandı. |
| `actualizar` | güncellemek | fiil | Se actualizó el sistema. — Sistem güncellendi. |
| `olvidar` | unutmak | fiil | Olvidé la cita. — Randevuyu unuttum. |
| `romper` | kırmak | fiil | Rompí el vaso. — Bardağı kırdım. |
| `abrir` | açmak | fiil | La puerta se abrió. — Kapı açıldı. |
| `saludar` | selamlamak | fiil | Se saludaron. — Birbirlerini selamladılar. |
| `peinarse` | saçını taramak | dönüşlü | Ana se peinó. — Ana saçını taradı. |
| `se venden` | satılıyor | pasif se | Se venden libros. — Kitaplar satılıyor. |
| `se busca a` | aranıyor | kişisiz se | Se busca a la responsable. — Sorumlu kişi aranıyor. |
| `se trabaja` | çalışılır | kişisiz se | Aquí se trabaja de noche. — Burada gece çalışılır. |
| `se me olvidó` | unuttum/aklımdan çıktı | istem dışı | Se me olvidó la cita. — Randevuyu unuttum. |
| `se nos olvidaron` | unuttuk | istem dışı çoğul | Se nos olvidaron las llaves. — Anahtarları unuttuk. |
| `fueron publicados` | yayımlandılar | ser edilgen | Los datos fueron publicados. — Veriler yayımlandı. |
| `están publicados` | yayımlanmış durumda | durum | Los datos están publicados. — Veriler yayımlanmış durumda. |
| `por parte de` | ... tarafından | fail belirtme | Hubo observaciones por parte del equipo técnico. — Teknik ekipten gözlemler geldi. |
| `con arreglo a` | ...e uygun | resmî | Se actuó con arreglo a la norma. — Kurala uygun davranıldı. |
| `a raíz de` | sonucunda | neden | Se revisó a raíz del error. — Hata üzerine incelendi. |

| `a diferencia de` | ...den farklı olarak | karşıtlık | A diferencia del caso anterior... — Önceki vakadan farklı olarak... |
| `en lo que respecta a` | ...e gelince | konu | En lo que respecta a privacidad... — Gizliliğe gelince... |

| `asumir la responsabilidad` | sorumluluğu üstlenmek | kalıp | Asumieron la responsabilidad. — Sorumluluğu üstlendiler. |
| `dejar constancia de` | kayıt altına almak | kalıp | Dejaron constancia del error. — Hatayı kayıt altına aldılar. |
| `dar a conocer` | duyurmak | kalıp | Se dieron a conocer los datos. — Veriler duyuruldu. |
| `poner en marcha` | başlatmak | kalıp | Se puso en marcha el proceso. — Süreç başlatıldı. |
| `llevar a cabo` | yürütmek | kalıp | Se llevó a cabo una revisión. — İnceleme yürütüldü. |

## Etkinleştirme

1. Türkçe sütununu kapatıp İspanyolca biçimi ve varsa artikeli/çoğulu üret.
2. Fiil ve kalıplarda en yakın doğal tamamlayıcıyı söyle.
3. Beş sözcüğü kendi hayatınla ilgili yeni cümlelere taşı.
4. Ertesi gün, üç gün sonra ve hafta sonunda kapalı notla yeniden üret.
