# DataCamp Associate AI Engineer for Developers

Study materials and notes for the [DataCamp Associate AI Engineer for Developers career track](https://app.datacamp.com/learn/career-tracks/associate-ai-engineer-for-developers).

## Workflow

1. Save course PDFs and other source materials in `pdfs/`.
2. Review each source together, with explanations and examples in the learning session.
3. Create or update a concise English note in `notes/` for each topic.
4. Add hands-on practice to `../../exercises/` and larger applied work to `../../projects/` when relevant.

## Organization

- `pdfs/` — original course PDFs and source materials
- `notes/` — organized topic notes derived from the materials

Start with the [Working with the OpenAI API notes](notes/working-with-the-openai-api.md), based on the first three course PDFs.
