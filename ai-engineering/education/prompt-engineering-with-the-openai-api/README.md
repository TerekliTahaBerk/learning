# Prompt Engineering with the OpenAI API

Study materials and notes for the [DataCamp Prompt Engineering with the OpenAI API course](https://app.datacamp.com/learn/courses/prompt-engineering-with-the-openai-api).

## Workflow

1. Keep original course PDFs in `pdfs/`.
2. Review each topic with explanations and examples.
3. Add concise English notes to `notes/` and keep them aligned with current API guidance.
4. Apply useful techniques in small experiments under `../../experiments/` or larger work under `../../projects/`.

## Organization

- `pdfs/` — original course PDFs
- `notes/` — organized notes derived from the course and current official documentation

Start with the [Prompt Engineering notes](notes/prompt-engineering-with-the-openai-api.md), based on the four supplied chapters.
