# Learning

A personal learning repository for exploring topics across different fields. It brings together notes, exercises, experiments, and projects created while learning from courses, books, documentation, and hands-on practice.

## Learning Areas

- [AI Engineering](ai-engineering/README.md) — notes, exercises, experiments, and projects related to AI engineering.
- [Spanish](spanish/README.md) — A1–B2 Spanish learning notes, vocabulary, exercises, and study materials for Turkish speakers.
- [YDS English](yds/README.md) — comprehensive English vocabulary, grammar, reading, translation, question strategies, and practice for Turkish-speaking YDS learners.

New learning areas can be added over time as interests and goals evolve.
